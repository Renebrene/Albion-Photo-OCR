# Планировщик (автоматизация)

Дата: 2026-10-17

## Расписание

`automation_settings` (schema/012 + 042):

- `mode = 'interval'` — запуск каждые `interval_minutes` минут;
- `mode = 'daily'` — один запуск в `daily_time` (HH:MM);
- `enabled` — общий выключатель; по умолчанию выключен.

`is_due()` в `app/jobs/automation.py`: в интервальном режиме сравнивает
`last_tick`, в дневном — ждёт указанное время и не повторяет тик в тот же день.

## Что делает тик

Только ставит в очередь уже поддержанные операции. **Авто-DINO удалён**: watcher
папки не реализуется, сортировка запускается явно («Обновление базы» или
кнопка в разделе «Сортировка»).

`auto_qwen` — «Запускать QWEN автоматически». **По умолчанию выключено.**
Если включено:

- планировщик ставит QWEN для фото без описания;
- конвейер «Обновление базы» запускает QWEN сразу после INGEST (после
  получения photo_id), параллельно DINO/HYBRID.

## Статистика

`GET /v1/automation` возвращает `last_run`:
`run_id`, `status` (DONE/STOPPED/FAILED/…), `started_at/finished_at`,
`counts`, `message`, `error_count`, `has_log`.

UI (вкладка «Автоматизация»): дата, бейдж «успешно/прервано/ошибка», сводка
заданий и кнопка «Лог» (текст читается по `run_id` через
`GET /v1/runs/history/{run_id}/log`).

## Логи

Хранятся отдельно от БД: `SCENE_RUN_LOG_ROOT` (по умолчанию `data/logs`),
файлы `{run_id}-{kind}.log`. Клиент не передаёт путь — только `run_id`.
