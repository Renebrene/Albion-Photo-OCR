# Умный поиск по медиа (фото/видео)

**Статус:** авто-режим и ручной режим (фото) реализованы. Запрос идёт через
очередь (`MEDIA_SEARCH`), inference выполняется только в воркере.

## Как устроено

Загруженный файл — временный: он пишется в `SCENE_SEARCH_QUERY_DIR`
(`data/media_search`), проверяется декодером (PIL для фото, OpenCV для видео) и
удаляется воркером в `finally`. В `video_assets` он не попадает.

QWEN описывает файл (описание/бренд/категория/клиент/теги), из этих полей
строятся фильтры, и по ним ищется фото по сохранённым метаданным QWEN. Второго
вызова модели нет — описание запроса сразу становится запросом.

Видео описывается покадрово: кадры берутся по фиксированным секундам ролика
(2, 4, 6 …), поиск идёт по каждому кадру, результаты объединяются (фото — сумма
без повторов, теги — объединение, описание/бренд/категория/клиент — первые
непустые).

## Режимы

Переключатель **«Авто»** рядом с кнопкой-камерой в строке поиска (активен по
умолчанию):

- **Авто** — выбранный файл сразу распознаётся и ищется; имя появляется в строке
  поиска чипом «имя (фото)», кнопка «ПОИСК» становится «ИИ-поиск», во время
  работы — «Стоп» (реальная отмена задания).
- **Ручной** (галочка снята) — открывается окно: превью выбранного файла,
  метаданные (имя, вес, размеры, дата изменения, текущая модель QWEN) и кнопка
  **«Распознать (QWEN)»**. После распознавания появляются редактируемые поля
  (описание, клиент, бренд, категория, теги); кнопки **«Поиск»** (искать по
  поправленным полям) и **«Отмена»** (закрыть).

### Маршруты

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/v1/search/media` | авто: описать и искать |
| POST | `/v1/search/media/describe` | ручной, шаг 1: только описать |
| POST | `/v1/search/query` | ручной, шаг 2: искать по фильтрам |
| GET | `/v1/jobs/media-search/{id}` | статус и результат задания |

Все три POST требуют scope `searches:write`. Задание `MEDIA_SEARCH` имеет три
формы payload: авто (`path` + `mode=auto`), describe (`path` + `mode=describe`,
поиск не выполняется) и query (`filters`, без файла и без QWEN).

## Ограничения и что дальше

- **Выбор кадра видео в ручном режиме не сделан**: сейчас в ручном режиме
  доступны фото; видео в ручном режиме описывается целиком (все фиксированные
  кадры), выбора одного кадра в окне нет — отдельный следующий шаг.
- **Проценты прогресса QWEN не показываются**: модель обрабатывает один файл без
  промежуточных шагов, поэтому окно показывает стадию, а не процент (для видео —
  «кадр N из M»).
- Результат по-прежнему часто определяют узкие поля (`client`, `category`);
  ранжирование по числу совпавших терминов — отдельная доработка.
