# Сравнение облачных VLM на кропах щитов — 2026-10-21

Задача: понять, какая облачная vision-модель дешевле и быстрее локальной
`qwen3-vl:4b-instruct` для чтения рекламных щитов, и сколько это стоит.

Замер сделан **независимо от рабочего стенда**: скрипты не трогают
PostgreSQL, очередь и настройки, оригиналы читаются только на чтение.

## Как воспроизвести

```bash
# 1. Десять кропов самых крупных щитов из тестового корпуса
.venv/bin/python scripts/cloud_vlm_crops.py --input test --count 10
#    -> /tmp/cloud_vlm_sample/manifest.json + crop_01..10.jpg

# 2. Прогон по моделям (OpenAI-совместимый endpoint)
export CLOUD_VLM_BASE_URL=https://openai.bothub.ru/v1
export CLOUD_VLM_API_KEY=...
.venv/bin/python scripts/cloud_vlm_bench.py \
    --models ling-3.0-flash-vl,mistral-small-3.2-24b-instruct,gemma-4-31b-it

# 3. Без отправки: показать план и цены
.venv/bin/python scripts/cloud_vlm_bench.py --dry-run
```

Результаты: `results.jsonl`, `summary.md`, `summary.json` в
`data/output/cloud_vlm_bench/<дата>/`. Стоимость берётся из публичного
прайса bothub (`/api/v1/pricing/models`) — RUB и USD за 1M токенов; для
другого провайдера передайте `--pricing` или `--no-pricing`.

Промпт — рабочий промпт кропа (`BILLBOARD_PROMPT`): description, client,
brand, category, tags ≤ 10. Ответ ограничен 768 токенами.

## Что не сработало

- **ling-3.0-flash** (без `-vl`): в каталоге помечен как vision, но API
  отвечает `No endpoints found that support image input` — не подходит.
- **gpt-5-nano**: 503 «Provider returned error» на всех 10 запросах
  (провайдер/маршрут недоступен в этот момент); gpt-4.1-nano работает.
- **ling-3.0-flash-vl**: дешёвая и по качеству нормальная, но upstream
  жёстко лимитирует — 46 с среднего ожидания и 60 % отказов 429. Для
  пакетного прогона без своего ключа не годится.
- **nemotron-3.5-super-vl**: генерирует до лимита и не закрывает JSON.

## Выводы

- **Самый дешёвый надёжный вариант — `mistral-small-3.2-24b-instruct`:**
  ~9 ₽ на 1000 фото, 4.9 с/фото, 100 % валидный JSON, заполняет client,
  brand и category.
- **`gemma-4-31b-it`** — быстрее (3.75 с) и чуть дороже (13.75 ₽/1000),
  также 100 % JSON.
- **`gpt-4.1-nano`** — 14.61 ₽/1000, но client/category чаще null.
- **`gemini-2.5-flash-lite`** — 27 ₽/1000; самый большой вход (1866 токенов
  из-за своей тарификации изображений), зато стабильно.
- **`deepseek-v4-flash-vision-exp`** — самый быстрый (3.09 с), но дороже
  (38.96 ₽/1000) и многословнее (385 выходных токенов).
- **Локальный `qwen3-vl:4b-instruct`** остаётся бесплатным и даёт 1.6–2.5 с
  на фото; облако имеет смысл для небольших порций, когда GPU занят, или
  как резерв при 429/недоступности Ollama.

## Ограничения замера

- Один корпус из 10 щитов одного адреса: качество на других баннерах может
  отличаться.
- Цены — тариф bothub на 2026-10-21; у провайдера есть наценка и курсовой
  множитель, они уже учтены в цифрах.
- Запросы шли последовательно; облачные провайдеры обычно держат
  параллельные запросы, поэтому пакет из 1000 фото можно ускорить, но
  упрётесь в лимиты тарифа (см. 429 у ling).
- Изображения уходят на внешний сервис — только по согласованию и без
  персональных данных.
