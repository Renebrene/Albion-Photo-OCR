# Мобильный PWA — Lighthouse-аудит

**Дата:** 2026-11-22  
**URL:** `http://127.0.0.1:8010/mobile/`  
**Lighthouse:** 11.7.1, Chrome headless, мобильный preset

## Результаты

| Категория | Оценка |
|---|---|
| Performance | **100** |
| Accessibility | **100** |
| Best Practices | **100** |
| PWA | **100** |
| SEO | **92** (намеренно: сайт закрыт от индексации) |

Метрики: FCP 1.3 с, LCP 1.7 с, TBT 0 мс, CLS 0, Speed Index 1.3 с,
общий вес страницы входа — 67 КиБ.

Аудит выполнялся на экране входа: это та же оболочка, манифест, Service
Worker и статика, которые получает авторизованный пользователь. После входа
контент другой, но PWA-инфраструктура и показатели оболочки те же.

## Что было исправлено по результатам

1. **`meta viewport`** — убраны `maximum-scale=1.0` и `user-scalable=no`;
   зум на мобильных больше не блокируется.
2. **Контраст экрана входа** — подзаголовок и подсказка переведены с
   `--text-light` на `--text-secondary`; код гостевого доступа — на
   `--text`, фон `--border`.
3. **Размер шрифта** — подсказка и `code` увеличены с 10–11 px до 12 px.
4. **`meta description`** добавлен в `mobile/index.html`.
5. **`/robots.txt`** — FastAPI отдаёт `User-agent: * / Disallow: /` вместо
   HTML-фолбэка SPA (раньше Lighthouse видел 39 ошибок robots.txt).

После этих правок Accessibility, Best Practices и PWA — 100.

## Оставшиеся замечания

| Аудит | Оценка | Почему оставлено |
|---|---|---|
| `is-crawlable` | 0 | Фотобаза приватная, индексация поисковиками запрещена намеренно. SEO-категория для закрытого приложения не является целевой. |
| `uses-long-cache-ttl` | 0.5 | Один ресурс; иконки PWA кешируются на сутки, чтобы обновление брендинга не застревало на год. |
| `render-blocking-resources` | 0 | Один CSS-файл, экономия ~150 мс; отложенная загрузка дала бы FOUC. |
| `unminified-javascript` | 0.5 | `main.js` намеренно читаемый; экономия ~6 КиБ. |
| `modern-image-formats` | 0.5 | Иконки PWA должны быть PNG по требованиям установки; экономия ~23 КиБ. |

## Воспроизведение

```bash
npx lighthouse http://127.0.0.1:8010/mobile/ \
  --output=json --output-path=/tmp/mobile-lighthouse.json \
  --chrome-flags="--headless=new --no-sandbox --disable-dev-shm-usage"
```

Для оценки авторизованного грида нужен отдельный прогон с реальной сессией;
текущий результат — аудит оболочки и экрана входа. Реальные iOS/Android
устройства по-прежнему требуют отдельной проверки.
