## Архитектура и ключевые инварианты

- **Фото:** `app/ingest/` проверяет/хеширует физический файл, `photo_id = PH_ + SHA256[:24]`; PostgreSQL identity/register работает отдельно от декодера. PREVIEW создаёт derived JPEG; originals read-only. Фото идут через очередь PostgreSQL jobs и worker.
- **Видео:** отдельный домен `video_assets`, `video_id = VI_ + SHA256[:24]`; `ffprobe` metadata + `ffmpeg -xerror` полная проверка; assets не попадают в `photos`, DINO/HYBRID/QWEN/photo-preview для видео не запускаются.
- **Распознавание:** DINO batch фиксирует membership; HYBRID требует успешный полный DINO batch; QWEN выполняется worker-ом, cloud/local provider config отдельный.
- **История:** `run_history` — индекс истории, не queue/source-of-truth. `job_queue`, `pipeline_runs/stages`, DINO/HYBRID tables остаются operational truth. Schema 037/038 на рабочей БД; отдельные run kinds сохраняются как `sort` для DINO/HYBRID без изменения CHECK constraint.
- **Web:** Vue/Quasar; FastAPI endpoints монтируются `/api`; API fail-closed bearer/session scopes. Фото/media fetch с bearer идёт через fetch/object URL, видео ticket download/playback — через краткоживущие cookies, потому что `<video>`/browser navigation не может передавать bearer.
- **Обработка вне request handler:** inference/transcode/trim выполняются jobs/workers; API enqueues и возвращает IDs.

Нормативные детали — `docs/ingest.md`, `docs/video.md`, `docs/pipeline_control.md`, `docs/run_history.md`, `docs/auth_roles.md`, `docs/qwen_process.md`, `docs/database_schema.md`. Архив `111/chatgpt_md` и анализы в нём исторические; сверять утверждения с текущим кодом.

## Явно отклонено или отложено

- **Folder watcher / auto-INGEST** — намеренно не реализуется: пользователь выбрал кнопочный запуск; запись новых данных должна быть явным действием.
- **DINO/QWEN on videos** — запрещено architecture boundary; не должны запускаться.
- **Full video editing NLE** (crop/multitrack/effects) — не сделан; реализован только trim-only editor, scope документирован.
- **Brand facet filter** — не сделан; договорились нормализовать через строку общего поиска.
- **1920p “light” profile** — не выбран: текущий “легко” 1440p, 720 strong, 1080 standard. Это конкретное отклонение исходного списка профилей, зафиксированное в `docs/video.md`.
- **Cloud link storage Albion** — реализовано как отдельный provider (`app/cloud/`) только для ограниченного upload-by-key endpoint; выключено до получения URL/ключа. Старый upload через админ-сессию + CSRF и текущая local Albion DB по-прежнему не считаются подходящей интеграцией.
- **OCR / QWEN-derived objects/colors/quality** — не подключены; QWEN используется как описатель/metadata helper, не authority.
- **Отдельные DINO/HYBRID run kinds** — пока `sort` kind с title; отдельные kind требуют forward migration/schema/API contract decision.

## Сомнительные решения и конкретные дефекты/риски

1. **[Закрыто 2026-10-17] Неполная предварительная INGEST-проверка видео.** `folder_stats()` теперь считает фото и видео, байты по видам, расширения и до 20 проблемных файлов; обход ограничен `SCENE_SOURCE_SCAN_LIMIT` и `SCENE_SOURCE_SCAN_TIMEOUT` (10 с по умолчанию). Содержимое не декодируется: это честно обозначено как предварительная проверка; полный `ffprobe`/`ffmpeg`/Pillow decode остаётся в `INGEST_DIR`.
2. **[Закрыто 2026-10-17] Общий lock между запусками сортировки.** `app/runs/coordination.py` сериализует launch фазу advisory-lock'ом, проверяет pipeline/scheduler/manual sort и блокирует конкурирующие старты (409); scheduler пропускает tick, UI опрашивает `/v1/runs/activity`. Осталось добавить richer reporting DTO, но конкурентный запуск закрыт.
3. **Run history counts могут быть semantic/summary-confusing.** В scheduler истории DINO и QWEN totals могут быть суммой фото-кандидатов в разных операциях, хотя это не всегда уникальные файлы; pipeline `counts.total` суммирует stage totals и тем самым одно фото может считаться на нескольких стадиях. Не использовать это поле как “уникально обработанные медиа” без уточнённого DTO.
4. **[Закрыто 2026-10-17] `jobs:write` включал редактирование QWEN provider API key/model.** `PUT /v1/qwen/settings` и `PUT /v1/qwen/model` теперь требуют `settings:write` (только Администратор); `unload` остаётся рабочей операцией `jobs:write`. UI скрывает/блокирует поля провайдера для Менеджера.
5. **Logs**: ограниченная структурированная запись — безопаснее stdout, но пользователь просил tail технического вывода этапа; именно общий stdout параллельных worker jobs не разделён на per-run. Имеющиеся логи дают ошибки/стадии, не полноценный stdout tail; не называть это “полный технический лог”.
6. **Media statistics date semantics:** SQL uses PostgreSQL `CURRENT_DATE`/`CURRENT_TIMESTAMP` vs Python `datetime.now`; подтвердить timezone semantics against deployment timezone, especially late-night local uploads. Current code uses `CURRENT_DATE` for ranges and timestamp creation for month counts.
7. **[Закрыто 2026-10-17] Guest video actions.** В `VideosGrid.vue` кнопки скачивания/сжатия, выбор для действий, редактирование title и trim-редактор скрыты для Гостя; playback не запрашивается, вместо него показывается «Просмотр доступен сотрудникам». Серверные scopes остаются последней линией защиты.
8. **Title/editor expectations:** video title is single `display_title`; photo QWEN description edit path is a separate media-search/edit workflow, not a general “edit entire photo card” form. Verify user means QWEN fields manually editable; if yes, only description/edit fields present in modal; full arbitrary persistent tags handling should be assessed.
9. **Docs have contradictory/stale statements.** `docs/run_history.md:14-16` says standalone DINO/HYBRID, scheduler and UI are not connected, contradicted by same document lines 51-58 and commit `be228d5`. `docs/project_assessment.md` has a detailed historical snapshot; its top update is newer than much of the body, but §4.1 and §§5–8 still state preview atomic publication, threshold, API, and rollout gaps as if current. Correct the document’s “historical” labeling/update, do not rewrite all historical analysis as current truth. `docs/frontend_quasar.md` has older “not implemented” claims; add current status banner/update rather than mass rewrite.
10. **Important QWEN integration test hazard:** previous full backend suite created 13 new history rows in production-like working DB; some pipeline rows may reference existing pipeline run ids. We did not delete rows, to avoid touching possibly real linked domain state. Test fixtures for external/live PostgreSQL need stronger transaction/unique probe isolation; new tests mostly unit mocks, but older `tests/test_pipeline_runs.py` use real DB and can leave rows. No active queue jobs remained at audit check. This is an operational data-hygiene issue, not a failing test.
11. **Folder precheck function is bounded by file count but uses `os.walk` with no per-directory timeout and returns full server path to authenticated staff.** Server root allowlist is present; very large/slow network mounts can still make synchronous scan check slow. Bound elapsed time and avoid displaying source roots unnecessarily.
12. **Video source consistency check** compares size + `st_mtime_ns` before/after hashing/probe/decode, not a second SHA; this is reasonable fast change detection but not cryptographic proof of immutable source under adversarial replacement. A safer, more expensive second hash is unnecessary by default; verify read-only mount and platform file handle semantics.
13. **Video list filters:** inspect `video_repository.list_videos` for date range validation (`date_from <= date_to`) and input query bounds; potential if invalid range silently yields empty. Not a critical correctness issue if API test coverage exists.
14. **GPU encoder concurrency**: auto NVENC worker count defaults to 1 and caps 2; CPU defaults half logical cores but systemd builder/video worker parallel config and other CPU workloads must be considered to avoid oversubscription.
15. **[Закрыто 2026-10-17] Bundle и object URL.** Маршруты переведены на lazy chunks: основной JS ~308 KB (≈111 KB gzip), отдельные PhotosGrid/Technical/VideosGrid/Help; предупреждение Vite >500 KB исчезло. `AuthImage` освобождает blob URL при размонтировании/смене кадра, незавершённые запросы не оставляют ссылку.
