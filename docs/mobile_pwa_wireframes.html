Ключевые решения

  • Frontend: Quasar v2 (Vite + Quasar plugin) — переиспользуем те же API-клиенты и компоненты, что и десктоп
  • Lazy loading: IntersectionObserver для загрузки превью при скролле
  • Cursor-based pagination: API возвращает next_cursor для бесконечного скролла
  • Кеш: IndexedDB для хранения до 500 превью
  • PWA: Service Worker + manifest.json (генерируется Quasar) для офлайн-режима
  • CSS Grid: Адаптивная раскладка (3-6 колонок) через Quasar QGrid
  • Group tabs: 5 табов (screens, rostov, cities, roads, small) — горизонтальная прокрутка под шапкой
  • Web Share API: Экспорт выбранных фото в мессенджеры через /api/v1/media-links

Этапы разработки

Этап Срок Результат
1. Каркас 1-2 дня HTML/CSS/JS скелет, API-клиент
2. Грид фото 2-3 дня Отображение фото с группировкой
3. Подвал 1-2 дня Переключатели режима, количества, периода
4. Избранное 2 дня Выбор, сохранение, экспорт
5. Меню 1-2 дня Бургер, логин, синхронизация
6. PWA 2-3 дня Офлайн-режим, оптимизация
ИТОГО 9-14 дней Рабочий PWA
