# Файлохранилище Albion: настройка и эксплуатация

Photobase выгружает выбранные фото и видео в файлохранилище Albion и хранит
только метаданные ссылки (`media_links`, schema/039). Оригиналы и превью
остаются в Photobase; наружу уходит копия файла.

Механизм общий для нескольких проектов; полный контракт токенов и endpoint'ов —
[`docs/integration/01_albion_tokens.md`](integration/01_albion_tokens.md).
Здесь — как это включить и как откатиться.

## 1. Что нужно на стороне Albion

1. Создать папку, в которую Photobase будет писать (например, `photobase`),
   и запомнить её `folder_id`.
2. Выпустить машинный токен с правами `upload` и `download`, привязанный к этой
   папке:

```bash
python manage_tokens.py add "Photobase" --scopes upload,download --folder <uuid>
```

Токен показывается **один раз**. Второй раз получить его нельзя — только
выпустить новый.

3. Убедиться, что хранилище слушает нужный порт и доступно с машины Photobase
   (LAN или интернет), а `ALBION_BASE_URL` на стороне Albion совпадает с
   публичным адресом: ссылки строятся от него.

## 2. Где настроить в Photobase

Технический раздел → вкладка **«Настройки»** → блок **«Файлохранилище Albion»**:

| Поле | Что это |
|---|---|
| Адрес | `https://files.example.ru` (без `/api/...`) |
| Папка | `folder_id` из Albion; можно оставить пустым, если папка уже привязана к токену |
| Срок ссылки, дней | TTL для `media_links.expires_at`, 1…3650 |
| Токен | `alb_…`; пустое поле при сохранении = «не менять», отдельная кнопка очищает |

Кнопка **«Проверить связь»** вызывает `GET /api/v1/integration/verify` и
показывает имя токена и его права. Это безопасно: файл не загружается.

Настройки хранятся в `app_settings` (ключи `albion_base_url`,
`albion_api_key`, `albion_folder_id`, `albion_ttl_days`) и перекрывают
переменные окружения. Менять их может только Администратор (`settings:write`).

## 3. Переменные окружения (fallback)

Если в БД ничего не сохранено, используются:

| Переменная | Смысл |
|---|---|
| `ALBION_BASE_URL` | базовый адрес хранилища |
| `ALBION_API_KEY` | машинный токен |
| `ALBION_FOLDER_ID` | папка (необязательно) |
| `ALBION_LINK_TTL_DAYS` | TTL ссылки, по умолчанию 90 |
| `ALBION_UPLOAD_TIMEOUT` | таймаут HTTP, по умолчанию 120 с |

Устаревшая `ALBION_UPLOAD_URL` ещё читается: из неё берётся только origin,
потому что новый контракт ждёт базовый адрес, а не готовый upload-endpoint.

## 4. Как проходит выгрузка

1. Пользователь выбирает фото/видео и нажимает облачную кнопку.
2. `POST /api/v1/media-links` создаёт записи `PENDING` и ставит задания
   `MEDIA_EXPORT` в очередь PostgreSQL.
3. Воркер (`scene-worker`) читает оригинал (только чтение), отправляет один
   файл на `POST /api/v1/integration/upload` с `X-API-Key`, папкой и TTL.
4. Albion возвращает обычную публичную ссылку; Photobase сохраняет её в
   `media_links` со статусом `READY` и `expires_at`.

TTL — это **метка в Photobase**, а не удаление файла: Albion не удаляет файлы
по сроку. Истёкшие ссылки отфильтровываются API и лениво помечаются `EXPIRED`.

## 5. Откат и отказоустойчивость

- **Настройки недоступны (БД)**: клиент использует env; если и там пусто —
  `configured=false`, кнопка выгрузки отвечает 503. Никаких «тихих» загрузок
  в неизвестное место.
- **Albion недоступен**: задание `MEDIA_EXPORT` завершается `FAILED` с
  безопасным текстом (без токена и путей); ссылка не создаётся.
- **Откат**: очистите адрес/токен в «Настройках» или удалите ключи
  `albion_*` из `app_settings`. Уже созданные ссылки остаются в истории
  `media_links`, но новые выгрузки недоступны (503).
- **Смена токена**: сохраните новый токен в UI — воркер читает настройки в
  момент выполнения задания, рестарт не нужен. Рестарт нужен только после
  изменения Python-кода.
- **Права**: токен с `upload` не получает доступ к админке Albion; отзыв токена
  мгновенно закрывает загрузки (`401` на следующем запросе).

## 6. Безопасность

- Токен хранится в `app_settings`/env, в API возвращается только маска
  (`…abcd`), в логах и текстах ошибок его нет.
- Адрес — только `http(s)`, без логина/пароля и без редиректов.
- Файл отправляется уже проверенным и сконвертированным; размер и тип
  контролируются на стороне Photobase, квоты — на стороне Albion.
- Ошибки Albion не содержат локальных путей.

## 7. Диагностика

| Симптом | Причина / что делать |
|---|---|
| 503 «Albion не настроен» | пусты `base_url`/`api_key` в БД и env |
| 422 «Albion отклонил токен» | токен отозван/просрочен или не тот |
| 422 «у токена нет права…» | выпущен без `upload` или без `--folder` |
| 422 «папка Albion не найдена» | неверный `folder_id` или папка удалена |
| 429 | лимит загрузок на токен; повторите позже |
| 507 | на хранилище нет свободного места |

## 8. Где это в коде

- `app/cloud/config.py` — настройки, маска, env-fallback.
- `app/cloud/albion.py` — `verify()`, `upload_file()`.
- `app/api/cloud.py` — `/v1/cloud/settings`, `/v1/cloud/verify`.
- `app/cloud/export.py` — задание `MEDIA_EXPORT` (без изменений по смыслу).
- `frontend/src/components/CloudSettings.vue` — форма настроек.
- `frontend/src/components/BaseSettings.vue` — вкладка «Настройки».
