# «Последний запуск»: сводка

Дата: 2026-10-17

Первым блоком вкладки «Последний запуск» идёт **сводка по видам запусков**,
остальные модули (история прогонов, DINO/HYBRID-карточки) сдвинуты ниже.

Источник — `GET /v1/runs/history?limit=50`; для каждого вида берётся последний
запуск:

| Вид | Что показывается |
|---|---|
| Обновление базы (pipeline) | статус; при STOPPED/FAILED — дата, этап остановки и причина (кнопка «Стоп» или ошибка); общая длительность и длительности этапов (INGEST/DINO/HYBRID/QWEN) |
| Ingest | статус, дата, длительность |
| Сортировка | статус, дата, длительность |
| QWEN | статус, дата, длительность |
| Планировщик | статус, дата, длительность |

У каждой строки, если лог существует, есть кнопка **«Лог»**: текст читается по
`run_id` (`GET /v1/runs/history/{run_id}/log`), путь к файлу клиенту не
раскрывается. Логи лежат в отдельном хранилище `data/logs`
(`SCENE_RUN_LOG_ROOT`).

Длительности этапов берутся из `stages[].seconds`, которые супервизор пишет в
`run_history` при каждом обновлении прогона.
