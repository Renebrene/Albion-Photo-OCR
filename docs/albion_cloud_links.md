# Albion: выгрузка медиа и ссылки (проект, не реализовано)

**Статус:** этап 6 дорожной карты заблокирован контрактом Albion. В PhotoBAse
сейчас нет cloud provider, таблицы ссылок и UI «Мои ссылки». Ничего не
развёрнуто; документ фиксирует требования и необходимые изменения, чтобы не
изобретать интеграцию.

## Что уже умеет Albion

По документации соседнего проекта `albion-files` (`docs/API.md`):

- `POST /upload` и `POST /upload_folder` (multipart) требуют **админ-сессию** и
  заголовок `X-CSRF-Token`; API-ключ `X-API-Key` предназначен только для
  автоматического **скачивания** (`/export_all`, файл по короткой ссылке).
- Публичные ссылки на файлы/папки не имеют параметра срока жизни. Временный ZIP
  `z/<uuid>` удаляется через 24 часа. Ссылки на 90 дней в контракте нет.
- Ошибки: 400/403/404/429; при 429 есть `Retry-After`. Ключ нельзя передавать в
  query string — только заголовком.

## Чего не хватает для требования PhotoBAse

Нужен один из двух вариантов, согласованный владельцем Albion:

1. **Предпочтительно:** server-to-server upload по API-ключу с отдельным scope
   (например, `X-API-Key` + `POST /api/upload`), который возвращает
   `{"links": [{"url": "...", "expires_at": "..."}]}` и умеет TTL 90 дней.
2. Либо отдельный ограниченный API-аккаунт/endpoint, где секрет хранится в
   env/secret store PhotoBAse, но **не** используется админ-пароль и не
   обходится CSRF-защита браузерной сессии.

Также нужны: идемпотентность загрузки (по SHA-256), rate/budget ответы,
endpoint отзыва ссылки и способ удалить объект по истечении срока.

## Предлагаемая схема PhotoBAse (после согласования)

- Очередь `MEDIA_EXPORT` (worker, не HTTP handler): выбирает фото/видео по ID,
  отправляет оригинал в Albion, получает ссылку и expiry.
- Таблица `media_links` (потребуется миграция, например `039_media_links.sql`):
  `link_id`, `owner_user_id`, `photo_id`/`video_id`, `provider`, `object_key`,
  `url`, `created_at`, `expires_at` (90 дней), `status`
  (`PENDING`/`READY`/`FAILED`/`EXPIRED`), `error_message`.
- API: `POST /v1/media-links` (scope `upload:write`/отдельный `links:write`),
  `GET /v1/media-links` — только свои ссылки; администратор видит все.
- UI: «Сохранить → Облако» с модальным окном и копируемым URL; «Мои ссылки» в
  шестерёнке; блок ссылок в техразделе для администратора/менеджера.
- Безопасность: URL не логировать, не помещать в метаданные фото, не отдавать
  ключи Albion; проверять принадлежность, срок и отзыв; фоновая очистка
  просроченных строк и, если Albion поддерживает, удаление объектов.
- Ошибки провайдера показывать как `FAILED` с безопасным сообщением, не
  раскрывая внутренние URL/учётные данные.

## Что нужно от владельца

- Какой endpoint/учётная запись Albion разрешена для загрузки из PhotoBAse.
- Где хранить секрет (env/secret store; не в репозитории и не в UI).
- Подтверждение TTL 90 дней и поведения после истечения/отзыва.
- Разрешение на миграцию `media_links` перед реализацией.

До ответа этап 6 остаётся заблокированным; остальные этапы аудита 1–5
реализованы и проверены.
