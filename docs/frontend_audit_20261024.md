Проверен живой код проекта `/home/alexice/projects/albion-photobase` (ветка

## 1. Архитектура и стек

| Слой | Стек | Файлы |
|---|---|---|
| Фронтенд | Vue 3.5 (`<script setup>`) + Quasar 2.17 + Pinia 2.2 + vue-router 4.4, сборка Vite 5, тесты Vitest 2 + @vue/test-utils | `frontend/src` |
| Бэкенд | Python + FastAPI + psycopg (PostgreSQL 16), Pydantic v2 | `app/api` |
| Хранилище | PostgreSQL (фото, метаданные, распознавания), диск (превью, слепки, оригиналы) | `data/` |
| Фоновые задания | SQLite-очередь `app/jobs/database.py` + воркеры под systemd (`scene-*.service`) | `app/jobs/worker.py` |
| Модели | DINOv2 (векторы), HYBRID (адрес), QWEN (описание через Ollama/OpenAI) | `app/dino`, `app/hybrid`, `app/qwen` |

Потоки, которые важно не смешивать (согласовано с `app/core` и
`docs/architecture_target.mmd`):

- **эталонный fingerprint** — отдельный SQLite-очередь (`app/pipeline/queue.py`) → `FingerprintManager.create()`; не путать с DINO-batch в PostgreSQL;
- **INGEST** — `DISCOVER → INTEGRITY → IDENTITY → REGISTER → RESULT`, SHA-256 физического файла, `photo_id = "PH_" + первые 24 hex`; исходники read-only;
- **DINO** — фиксированный batch, состав не меняется после ingest;
- **HYBRID** — читает сохранённые DINO-результаты, сам inference не запускает;
- **PREVIEW** — производные изображения отдельно от оригиналов.

API: 138 маршрутов на трёх роутерах (`app/api/routes.py` — 118,
`app/api/videos.py` — 17, `app/api/cloud.py` — 3); остальные 12 файлов
`app/api/` — сервисные модули без маршрутов. Роли: `Администратор` (`*`),
`Менеджер` (14 scope), `Гость` (`read`); `settings:write` и `users:manage` —
только администратор. Rate limit выключен по умолчанию
(`SCENE_API_RATE_LIMIT=0`), lockout входа включён (10 попыток / 600 с).
