# Сравнение Qwen3-VL 4B и Qwen2.5-VL 7B

Дата: 2026-10-17 · стенд: `scripts/qwen_model_compare.py` · 20 кропов щитов,
один промпт, `num_ctx=8192`, `num_predict=600`, `temperature=0`.

| Модель | JSON OK | Бренд | Клиент | Описание | Ошибки | Ср. сек* |
|---|---|---|---|---|---|---|
| `qwen3-vl:4b-instruct` | 20/20 | 15 | 5 | 20 | 0 | 2.33 |
| `qwen2.5vl:7b` | 20/20 | 11 | 16 | 20 | 0 | 3.94 |

\* среднее без первого запроса (загрузка модели): 10.3 с у 4B против 52.5 с у 7B.

## Вывод

- Обе модели дают полностью валидный JSON на всех 20 кропах.
- **4B быстрее** (2.33 с против 3.94 с) и заметно быстрее стартует
  (10 с против 52 с загрузки).
- 4B чаще извлекает **бренд** (15 против 11), 7B чаще — **клиента**
  (16 против 5). Для карточки важны оба поля; суммарно 4B даёт более
  сбалансированный результат, а клиента можно добрать нормализацией.
- 7B иногда возвращает строку `"null"` вместо JSON-null — требует
  дополнительной нормализации.

**Решение:** рабочей остаётся `qwen3-vl:4b-instruct`. `qwen2.5vl:7b` оставлена
установленной для экспериментов; переключается в «Распознавание → Провайдер
QWEN» без перезапуска.

Сырые результаты: `data/output/qwen_model_compare/compare_*.json|md`
(в git не попадают).
