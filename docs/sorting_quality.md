# Оценка качества сортировки без QWEN

Дата: 2026-10-23

## Зачем

Адрес фото даёт DINO/HYBRID, а QWEN к нему отношения не имеет. Значит на
корпусе, где файлы подписаны названием, похожим на юридический адрес, можно
проверить сортировку **не запуская QWEN** — это часы экономии и честная
картина того, как система справляется с фото, для которых есть и нет слепков.

`scripts/evaluate_sorting.py` только читает базу:

- эталон берётся из имени файла (`Радиаторный_24.JPG` → «Радиаторный /
  Вавилова»); хвостовой номер копии отбрасывается, имя и адрес сравниваются
  в обе стороны с нормализацией как в «Уточнении» (регистр, пробелы,
  юридические формы, латиница/кириллица). Неоднозначные имена в оценку не
  входят;
- предсказание — тот же адрес, что видит грид (с учётом порогов);
- фото без адреса, но с вердиктом считаются попавшими в «Требуют проверки»,
  а не ошибкой;
- отдельно перечисляются адреса из эталона, у которых **нет активного
  слепка**: их распознать нечем, и вины модели здесь нет.

```bash
# как сейчас (пороги из настроек)
.venv/bin/python scripts/evaluate_sorting.py

# конкретные пороги, не меняя настройки
.venv/bin/python scripts/evaluate_sorting.py --min-margin 0.015
.venv/bin/python scripts/evaluate_sorting.py --low-score 0.85 --json

# только папка (например, свежий размеченный корпус)
.venv/bin/python scripts/evaluate_sorting.py --folder /mnt/photos/тест
```

## Базовая линия на корпусе 23.10.2026

Из 1518 фото адрес угадывается по имени у 375 (остальные названы `95_079.JPG`
или сокращениями, по которым нельзя однозначно определить адрес).

| Настройка | Верно | Другой адрес | В «Требуют проверки» |
|---|---:|---:|---:|
| без порогов | 372 | **3** | 0 |
| **отрыв ≥ 0.015** | 355 | **0** | 20 |
| сходство ≥ 0.85 | 336 | 1 | 38 |

Все три ошибки без порогов — те самые, что владелец исправлял вручную
(`Радиаторный_24`, `Ленина125_03`, `Радиаторный_25`), и у всех отрыв
0.005–0.010. Порог отрыва 0.015 убирает их полностью, отправляя в проверку
5 % фото; порог по сходству 0.85 и пропускает одну ошибку, и отвлекает почти
вдвое больше фото.

## Ограничения

- Оценка зависит от того, насколько имя файла действительно содержит адрес.
  На корпусе с произвольными именами (`IMG_1234.JPG`) измерять нечего —
  скрипт честно покажет «без адреса в имени».
- Неоднозначные имена (подходят два адреса одинаковой длины) исключаются, а
  не угадываются.
- Адреса без активного слепка в оценке видны отдельной строкой: это пробел в
  эталонах, а не ошибка сортировки.
