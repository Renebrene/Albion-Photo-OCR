# Диагностика осиротевших HYBRID-запусков

Исходный снимок `photobase_ingest_test`, **2026-10-18**. Первичная диагностика
(`scripts/audit_orphan_hybrid.py --format json`) была read-only. После отдельного
подтверждения владельца 47 найденных пар переведены из ложного `PENDING/DONE`
в терминальный `FAILED`; строки не удалялись. Полная копия исходных 47 строк
сохранена локально в `/home/alexice/scene-fingerprint-backups/orphan_hybrid_20261018_full_rows_pre_repair.json` (режим `0600`).

## Результат

В исходном снимке найдено **47** строк `hybrid_runs` со статусом `PENDING`, для
которых нет `HYBRID_RUN` job в `job_queue`. У каждой пары:

- HYBRID: `total_count=1`, `completed_count=0`, `failed_count=0`, нет начала,
  завершения или result rows;
- DINO batch: `NORMAL`, `DONE`, `total_count=1`, `completed_count=1`,
  `failed_count=0`;
- фактическое число `dino_runs` — **0**, candidate rows — **0**;
- HYBRID jobs — **0**, связанных sort-history rows — **0**.

Это противоречивое состояние: сохранённые batch counters говорят о выполнении
DINO, но входные DINO run/candidate rows отсутствуют, поэтому HYBRID запускать
нельзя. В БД также есть два пустых DINO batch со статусом DONE/total=0; без
HYBRID-записи они не входят в orphan-набор и выглядят как штатные zero-work
batch.

## Оценка причины и ограничение

Код до исправления создавал HYBRID row, затем отдельной операцией ставил job в
очередь; падение процесса/ошибка enqueue между операциями могло оставить
`PENDING` row. Однако отсутствующие DINO input rows не объясняются одной этой
ошибкой. Точный источник данных доказать по сохранённым строкам нельзя; тестовая
очистка/удаление связанного DINO input — возможная, но неподтверждённая причина.

Новые API, auto-HYBRID и supervisor пути переведены на атомарное создание
HYBRID row + queue job (+ history link): будущий сбой постановки не должен
оставлять такую половинчатую пару.

После отдельного подтверждения владельца все 47 HYBRID-записей и ровно 47
связанных пустых DINO batch помечены `FAILED` в одной транзакции. Строки и
идентификаторы сохранены, ничего не удалялось; исходные значения записаны в
backup JSON выше с правами `0600`. Проверка после транзакции: 47/47 пар имеют
статус `FAILED`, повторный read-only audit показывает `pending_orphans=0`.
Результаты HYBRID восстановить нельзя: отсутствуют DINO runs и candidates.
