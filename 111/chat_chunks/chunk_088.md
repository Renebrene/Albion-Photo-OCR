
При этом:

- `(3)` — **3 уникальных адреса**;
- несколько фотографий одного адреса считаются **одним адресом**;
- старые фотоотчёты не увеличивают число;
- берём **последнюю дату фотоотчёта**;
- если на последней дате у клиента нет фотографии по адресу — этот адрес не считается;
- список клиентов также формируется из данных PostgreSQL, а не из захардкоженного `STATE.clients`.

Это важное уточнение: текущий `get_clients_with_address_counts()` считает адреса **по всей таблице**, поэтому его теперь нужно переделать на логику **последнего фотоотчёта**.
