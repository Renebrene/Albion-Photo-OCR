### Внутри одного фильтра

Здесь есть важное различие.

Если выбрано несколько клиентов:

> Клиент 1 **ИЛИ** Клиент 2

и несколько адресов:

> Адрес 5 **ИЛИ** Адрес 8

то итог:

```text
(Клиент 1 ИЛИ Клиент 2)
        И
(Адрес 5 ИЛИ Адрес 8)
        И
(Менеджер Иванов)
        И
(Август)
```

То есть **между группами — И**, а **внутри выбранных элементов одной группы — ИЛИ**.

Это стандартная и наиболее удобная логика для чекбоксов.

### Подборки тоже работают так же

Например, подборка клиентов:

> «VIP»

содержит 5 клиентов.

Выбираем её → это эквивалентно выбору этих 5 клиентов вручную.

А если одновременно выбрана подборка адресов:

> «Центр»

то получаем:

```text
(VIP-клиент 1 ИЛИ VIP-клиент 2 ИЛИ ...)
                    И
(Адрес из подборки «Центр»)
                    И
(текущий менеджер)
                    И
(остальные фильтры)
```

**Это стоит заложить именно в ядро фильтрации**, а не реализовывать отдельно для интерфейса. Тогда неважно, выбраны элементы вручную или через подборку — результат фильтрации будет абсолютно одинаковым.

Но внутри одного типа фильтра:



Это должно быть реализовано **одним общим механизмом фильтрации**, а не отдельными обработчиками для каждого элемента интерфейса.

## Общая концепция поиска

У нас постепенно складывается единая система:

```text
                    ПОИСК
                      │
        ┌─────────────┼─────────────┐
        │             │             │
     ФИЛЬТРЫ       ТЕКСТ         МЕДИА
        │             │             │
   ┌────┴────┐        │        ┌────┴────┐
   │         │        │        │         │
Клиенты   Адреса   текстовый  Фото      Видео
                     поиск
```

При этом **фильтры ограничивают область поиска**, а умный поиск ищет внутри неё.

---

# 1. Множественный выбор клиентов

Обязательно оставить:

```text
☑ Клиент 1
☑ Клиент 5
☑ Клиент 17
```

Это означает:

```text
Клиент 1 OR Клиент 5 OR Клиент 17
```

То есть пользователь может выбрать любое количество клиентов.

Подборка клиентов фактически является сохранённым набором такого множественного выбора.

---

# 2. Множественный выбор адресов

То же самое:

```text
☑ Адрес 12
☑ Адрес 35
☑ Адрес 48
☑ Адрес 102
```

Логика:

```text
Адрес 12 OR Адрес 35 OR Адрес 48 OR Адрес 102
```

---

# 3. Между группами — И

Получается очень мощная конструкция:

```text
(Клиент 1 OR Клиент 5 OR Клиент 17)
                    AND
(Адрес 12 OR Адрес 35 OR Адрес 48)
                    AND
(Дата/время)
                    AND
(прочие фильтры)
```

А затем поверх этого можно запускать умный поиск.

---

# 4. Умный поиск по тексту

Например пользователь выбирает:

**Клиенты:**

```text
☑ Иванов
☑ Петров
```

**Адреса:**

```text
☑ Ленина 15
☑ Ленина 27
☑ Мира 8
```

и пишет:

> найти фотографии с красным баннером и белой машиной

Получается:

```text
ФИЛЬТР:
(Иванов OR Петров)
AND
(Ленина 15 OR Ленина 27 OR Мира 8)

                    ↓

УМНЫЙ ПОИСК:
"красный баннер и белая машина"

                    ↓

РЕЗУЛЬТАТ
```

То есть поиск **не должен сканировать всю фотобазу**, если пользователь уже сузил область.

---

# 5. Умный поиск по изображению

Например пользователь загружает фотографию баннера.

Система:

```text
выбранные клиенты
        +
выбранные адреса
        +
изображение-запрос
        ↓
поиск похожих фотографий
```

Здесь как раз пригодятся наши существующие механизмы:

**DINOv2 / fingerprint → кандидаты → поиск похожего изображения.**

А затем можно будет дополнительно использовать OCR/LLM для уточнения.

---

# 6. Умный поиск по видео

Аналогично:

```text
Видео
 ↓
кадры / ключевые кадры
 ↓
поиск похожих сцен
 ↓
фильтрация по клиентам/адресам
 ↓
результаты
```

Причём видео можно будет искать не только как целый объект, но и:

> «Найди фотографии, где встречается то, что есть на этом видео».

Это уже получается довольно серьёзный поисковый механизм.

---

# 7. Поэтому фильтры нужно сделать независимыми от способа поиска

Это ключевой архитектурный момент.

Не делать:

```text
поиск по тексту → свой фильтр
поиск по фото → свой фильтр
поиск по видео → свой фильтр
```

А сделать единую модель:

```text
                     QUERY
                       │
        ┌──────────────┴──────────────┐
        │                             │
   STRUCTURED                    SMART QUERY
    FILTERS                       SEARCH
        │                             │
        ├─ менеджеры                  ├─ текст
        ├─ клиенты                    ├─ изображение
        ├─ адреса                     └─ видео
        ├─ дата
        └─ другие
        │
        └──────────────┬──────────────┘
                       ↓
                 SEARCH ENGINE
                       ↓
                    РЕЗУЛЬТАТ
```

Тогда пользователь сможет делать, например:

> **Менеджер:** Иванов  
> **Клиенты:** 3 клиента  
> **Адреса:** 12 адресов  
> **Дата:** июль–август  
> **Запрос:** фотография с таким же баннером

И система сначала ограничит область:

**12 адресов × 3 клиента**, а уже потом выполнит поиск.

from nicegui import ui
from app.core.config import settings
from app.core.embedder import SceneEmbedder
from app.core.fingerprint import FingerprintManager
from app.core.recognizer import SceneRecognizer

embedder = SceneEmbedder(settings)
manager = FingerprintManager(settings, embedder)
recognizer = SceneRecognizer(settings, embedder, manager)

@ui.page("/")
def page():
    ui.label("Scene Fingerprint").classes("text-3xl font-bold")
    ui.label("Распознавание локации по визуальному окружению").classes("text-lg text-gray-600")

    with ui.tabs().classes("w-full") as tabs:
        create_tab = ui.tab("Создать слепок")
        recognize_tab = ui.tab("Распознавание")
        db_tab = ui.tab("База слепков")

    with ui.tab_panels(tabs, value=create_tab).classes("w-full"):
        with ui.tab_panel(create_tab):
            ui.label("Новый визуальный слепок").classes("text-2xl")
            fp_id = ui.input("ID локации / конструкции", placeholder="78").classes("w-96")
            folder = ui.input("Папка эталонных фотографий", value="data/input/78").classes("w-full")
            info = ui.label("")

            def create():
                try:
                    r = manager.create(fp_id.value.strip(), folder.value.strip())
                    info.text = f"Создан: {r['id']} | {r['images']} фото | {r['dimension']}D"
                except Exception as e:
                    info.text = f"Ошибка: {e}"

            ui.button("СОЗДАТЬ СЛЕПОК", on_click=create)

        with ui.tab_panel(recognize_tab):
            ui.label("Распознавание папки").classes("text-2xl")
            folder2 = ui.input("Папка", value="data/input/new").classes("w-full")
            topk = ui.number("Top-K", value=5, min=1, max=20).classes("w-32")
            threshold = ui.number("Порог", value=0.65, min=0, max=1, step=0.01).classes("w-32")
            results_box = ui.column().classes("w-full")

            def run_recognition():
                results_box.clear()
                try:
                    rows = recognizer.recognize_folder(
                        folder2.value, int(topk.value), float(threshold.value)
                    )
                    with results_box:
                        for row in rows:
                            ui.label(
                                f"{Path(row['file']).name} → "
                                f"{row['best_id'] or 'UNKNOWN'} "
                                f"{row['score']:.3f}"
                            )
                            for c in row["candidates"]:
                                ui.label(f"    {c['id']}: {c['score']:.3f}").classes("text-gray-500")
                except Exception as e:
                    with results_box:
                        ui.label(f"Ошибка: {e}")

            ui.button("РАСПОЗНАТЬ", on_click=run_recognition)

        with ui.tab_panel(db_tab):
            ui.label("База слепков").classes("text-2xl")
            rows = ui.column().classes("w-full")

            def refresh():
                rows.clear()
                with rows:
                    data = manager.list_fingerprints()
                    if not data:
                        ui.label("База пуста.")
                    for x in data:
                        ui.label(
                            f"№{x['id']} — {x['images']} фото — "
                            f"{x['dimension']}D — {x['model']}"
                        )

            ui.button("Обновить", on_click=refresh)
            refresh()

ui.run(host=settings.host, port=settings.port, title="Scene Fingerprint")
