## 🔧 1. **Проверка модели `llama3.2-vision:11b`**

Ошибка:

```
unknown model architecture: 'mllama'
```

**Причина:**  
Модель `llama3.2-vision:11b` использует архитектуру `mllama`, которая не поддерживается вашей версией Ollama (0.32.13).  

**Решение:**  
1. Убедитесь, что модель действительно существует в вашем Ollama:  
   ```bash
   ollama list
   ```

2. Проверьте, не устарела ли модель:  
   ```bash
   ollama show llama3.2-vision:11b
   ```

3. Если модель не отображается, попробуйте загрузить её вручную:  
   ```bash
   ollama pull llama3.2-vision:11b
   ```

4. Если модель всё ещё не работает, **временно исключите её из теста** и сосредоточьтесь на Qwen3-VL.

## 🔄 2. **Исправление контекста для Qwen3-VL**

Ошибка:

```
request (4131 tokens) exceeds the available context size (4096 tokens)
```

**Решение:**  
1. Увеличьте `num_ctx` до `16384` в запросе:  
   ```python
   "options": {
       "num_ctx": 16384,
       "temperature": 0
   }
   ```

2. Уменьшите размер изображений до `1600px` (по длинной стороне) перед отправкой:  
   ```python
   def image_to_base64(path):
       img = Image.open(path)
       img.thumbnail((1600, 1600))
       buf = BytesIO()
       img.convert("RGB").save(buf, format="JPEG", quality=90)
       return base64.b64encode(buf.getvalue()).decode()
   ```
