### 📌 **Итоговая стратегия для рекламного отдела**

#### 1. **Обработка фотографий (Scene Recognition)**
- **Вход:** 200–300 фотографий в день (3500x2500, 4.5 МБ каждая)
- **Выход:** Каталоги по адресам (78–85)
- **Технологии:**
  - **DINOv2 embedding** для изображений (50–150 мс на GPU)
  - **FAISS** для быстрого поиска по базе эталонных конструкций
  - **OCR** для дополнительной проверки (если требуется)
- **Оптимизация:**
  - Прогоняем оригинальные макеты один раз → сохраняем embeddings и OCR
  - Далее, при обработке новых фото, используем уже готовые данные

#### 2. **Поиск по заданиям (Banner Search + Text Search)**
- **Вход:** Задание (оригинал/видео/текст)
- **Выход:** Список фотографий, соответствующих заданию
- **Технологии:**
  - **DINOv2** + **FAISS** для поиска по изображениям
  - **OCR** + **поиск по тексту** (если задание текстовое)
  - **Сегментация видео** + **representative frames** для ускорения
- **Оптимизация:**
  - Используем **two-stage search**: сначала по изображению, потом по тексту
  - Устанавливаем пороги для уверенности (например, 0.85+ для изображений, 0.9+ для текста)

#### 3. **Сохранение результатов**
- **Формат:** CSV + HTML-отчет
- **Пример:**
  ```csv
  photo,construction,address,timestamp,score
  photo_001,78,ул. Ленина,14:30,0.91
  photo_002,83,ул. Пушкина,14:35,0.88
  ```
- **Дополнительно:** Каталог с копиями найденных фото

---

### 🚀 **Производительность на RTX 3060**
- **Обработка 200 фото:**
  - DINO + FAISS: ~10–20 сек
  - OCR: ~10–30 сек (если нужно)
- **Обработка видео (15 сек):**
  - Сегментация + DINO: ~3–10 сек
  - OCR: ~5–15 сек (если нужно)
- **Общее время:** 15–30 сек на 200 фото + видео

### 🧠 **Ключевые моменты**
1. **Разделение задач:** Scene Recognition → Banner Search → Text Search
2. **Однократная обработка оригиналов:** Экономия времени и ресурсов
3. **Двухступенчатый поиск:** Увеличивает точность и скорость
4. **Модульность:** Упрощает масштабирование и поддержку
