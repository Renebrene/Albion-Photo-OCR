## 1. ЗАДАЧА  
Разработать backend-модуль для сбора и отображения системной информации (CPU, RAM, GPU, диск, сеть, температура) с автоматическим обновлением данных.  

---

## 2. ФАЙЛЫ И МОДУЛИ  
- `app/web/system/monitor.py` — модуль для сбора системной информации (CPU, RAM, GPU, диск, сеть, температура).  
- `app/web/system/__init__.py` — файл для создания пакета `system` в директории `app/web/system`.  

---

## 3. АРХИТЕКТУРА  
- **Технология/фреймворк**: Python с использованием стандартных библиотек (`subprocess`, `shutil`, `platform`, `pathlib`) для системных вызовов и анализа данных.  
- **Паттерны проектирования**: Модульный подход (отдельные функции для каждого типа данных), функциональное программирование (чистые функции без побочных эффектов).  
- **Структура данных**: Словарь с ключами, представляющими параметры системы (например, `cpu`, `memory`, `disk`, `network`).

## 6. КЛЮЧЕВЫЕ РЕШЕНИЯ  
- **Создание отдельного пакета `system`**: Для организации кода и избежания конфликтов импортов.  
- **Модульный подход**: Разделение функционала на отдельные методы для удобства тестирования и поддержки.  
- **Автоматическое обновление данных**: Использование `collect()` для формирования живого состояния системы с интервалом.  
- **Форматирование скорости сети**: Перевод байт в MB/s/GB/s для удобочитаемости.
