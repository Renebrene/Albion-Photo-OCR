### 🧠 **Анализ и решение**

#### 1. **Что мы знаем**
- **Watcher** обнаруживает новые/изменённые файлы.
- **photo_ingest.py** запускается после стабильности файла.
- **preview** сейчас создаётся **после Hybrid**, через отдельный скрипт.
- **Grid** показывает фото только после **DINO + Hybrid**.
- **preview_path** и **preview_status** — часть модели фото.

#### 2. **Что нужно сделать**
- **Перенести создание preview на раннюю стадию** — сразу после `photo_ingest`, но **до DINO/Hybrid**.
- **Не менять логику grid** — он всё равно ждёт DINO + адрес.
- **Использовать существующий `create_preview()`** из `scripts/create_previews_v01.py`, но **не через Hybrid output**.

#### 3. **Как это сделать**
- В `photo_ingest.py` добавить:
  ```python
  from scripts.create_previews_v01 import create_preview
  ```
- После создания `photo_id`, но **до запуска DINO/Hybrid**, добавить:
  ```python
  source_path = Path(photo_path)
  destination_path = preview_root / source_path.name.replace(".jpg", ".jpg")  # или ваша логика
  result = create_preview(source_path, destination_path)
  preview_status = "done" if result == "created" else "pending"
  ```
- Обновить модель данных: `preview_path`, `preview_status` — часть `photo` в БД.

#### 4. **Почему это работает**
- **preview** становится частью фото, а не отдельным этапом.
- **Grid** всё равно ждёт DINO + адрес, но **preview** уже готово.
- **DINO/Hybrid** не зависят от preview — они работают независимо.
- **Старый скрипт** `create_previews_v01.py` становится **ненужным**, так как preview создаётся на ранней стадии.

#### 5. **Потенциальные проблемы**
- **Ошибка при создании preview** — нужно обработать исключения, чтобы не останавливать обработку.
- **Конфликт имен** — убедиться, что `preview_root` и `create_preview()` не пересекаются с существующими путями.
- **Дублирование кода** — если `create_preview()` используется в нескольких местах, стоит вынести его в отдельный модуль.

#### 6. **Итог**
- **Да, стоит переносить preview на раннюю стадию** — это улучшает архитектуру и ускоряет доступ к превью.
- **Не менять логику grid** — он всё равно ждёт DINO + адрес.
- **Используйте существующий код** `create_preview()` для избежания дублирования.
- **Проверьте, где запускается `photo_ingest`**, чтобы вставить создание preview в правильное место.
