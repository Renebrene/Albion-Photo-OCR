Чтобы адаптировать вывод Qwen в формат, совместимый с Hybrid v12, необходимо выполнить следующие шаги:

### 1. **Анализ структуры вывода Qwen**
Файлы вывода Qwen (например, `Нагибина24_11.json`) содержат структурированные данные в формате JSON. Пример содержимого:
```json
{
  "client": "Компания X",
  "brand": "Бренд Y",
  "category": "Реклама",
  "text": ["Текст 1", "Текст 2"],
  "colors": ["Красный", "Белый"],
  "objects": ["Экран", "Логотип"],
  "description": "Баннер с логотипом и текстом на красном фоне.",
  "banner_type": "видеоэкран",
  ...
}
```
Такой формат не совместим напрямую с Hybrid v12, который требует `top1..top5` и их оценок.

---

### 2. **Адаптация вывода Qwen в формат Hybrid v12**
Функция `adapt_recognizer_rows` преобразует данные Qwen в нужный формат. Однако важно убедиться, что:
- Каждый файл Qwen содержит хотя бы один кандидат (например, `top1`).
- Если кандидатов меньше 5, оставшиеся `top2..top5` заполняются `None` или отбрасываются.
- Оценки (`score`) из Qwen корректно преобразуются в числа (`float`).

Пример адаптированного вывода:
```json
{
  "top1": "id_123",
  "top1_score": 0.95,
  "top2": "id_456",
  "top2_score": 0.88,
  ...
}
```

---

### 3. **Проверка работы Hybrid v12**
Функция `hybrid_v12` использует адаптированные данные для вычисления итогового `best_id` через:
- **Глобальные оценки** (`GLOBAL_WEIGHT` для `top1..top5`).
- **Подкатегории** (`sub_id`) с бонусами при совпадении с родительским ID.
- **Консенсус соседей** (если `top1` соседних строк совпадает, добавляется +3.0 к оценке).

Важно:
- Убедиться, что `sub_id` и `parent` корректно связаны.
- Проверить, что `neighbors` корректно вычисляются из `rows`.

---

### 4. **Потенциальные ошибки и исправления**
- **Отсутствие кандидатов**: Если в Qwen-файле нет `top1`, `adapt_recognizer_rows` должен обработать это (например, установить `None`).
- **Некорректные оценки**: Убедитесь, что `score` из Qwen преобразуется в `float` (например, `0.95` вместо `"0.95"`).
- **Формат JSON**: Проверьте, что адаптированные данные сохраняются в JSON-файлы без ошибок (например, через `json.dumps`).
