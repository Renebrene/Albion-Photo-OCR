### ✅ **Итоговая замена**

#### 1. **Устанавливаем `grid_requested = True` сразу после построения индекса**
Изменяем:

```python
grid_requested = False
```

на:

```python
grid_requested = True
```

#### 2. **Убираем обязательное нажатие кнопки**
Оставляем кнопку, но убираем её обязательность. Вместо `on_click` используем `on`, чтобы кнопка оставалась, но не требовала клика.

#### 3. **Автоматический запуск `request_photo_grid()`**
После `build_photo_index()` вызываем `request_photo_grid()` вручную, чтобы грид сразу загрузился.
