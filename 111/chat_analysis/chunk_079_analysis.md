### 📌 **Техническое окно: реализация по пожеланиям**

Вот как будет выглядеть техническое окно с учетом всех пожеланий. Все разделы будут разделены, и мы сохраним структуру `technical.py` с возможностью расширения.

---

## 📁 **Файлы и структура**

### 1. `app/web/settings.py` (уже создан)
- Менеджеры, цвета, тема, настройки интерфейса.

### 2. `app/web/state.py`
- Текущее состояние приложения: менеджеры, тема, слепки, клиенты, адреса.

### 3. `app/web/technical.py`
- Основное техническое окно с вкладками.

---

## 📌 **Техническое окно: вкладки**

### 📌 **1. Менеджеры**

#### 📌 Функции:
- Добавление нового менеджера.
- Архивирование менеджера (удаление из списка).
- Выбор текущего менеджера.
- Настройка цвета менеджера.
- Смена цвета влияет на:
  - цветовую гамму интерфейса.
  - доступную подборку.
  - список клиентов (фильтрация по менеджеру).

#### 📌 UI:
- Список менеджеров с возможностью выбора.
- Кнопка **"Добавить менеджера"**.
- Кнопка **"Архивировать"**.
- Слайдер или выбор цвета для каждого менеджера.

#### 📌 Логика:
- При выборе менеджера:
  - Обновляется цвет интерфейса.
  - Фильтруются клиенты (если включено).
  - Обновляется подборка (если включено).

---

### 📌 **2. Тема интерфейса**

#### 📌 Функции:
- Переключение между светлой и темной темой.
- Цвета менеджеров сохраняются в темной теме.

#### 📌 UI:
- Переключатель: ☀️ / 🌙.
- Статус текущей темы в заголовке.

#### 📌 Логика:
- При смене темы:
  - Обновляется цвет интерфейса.
  - Цвета менеджеров остаются неизменными.

---

### 📌 **3. Создание / пересоздание слепков**

#### 📌 Функции:
- Выбор адреса.
- Выбор фотографий (50–100 шт.).
- Присвоение имени и описания.
- Процесс-бар с прогрессом.
- Статистика: количество обработанных фото, ошибки.
- Создание нового элемента в разделе **Адреса**.
- Лог даты создания/пересоздания слепка.

#### 📌 UI:
- Список адресов.
- Кнопка **"Создать слепок"**.
- Форма для ввода имени и описания.
- Progress bar с текущим этапом.
- Статистика: "Фото обработано: 82/100".

#### 📌 Логика:
- При создании слепка:
  - Добавляется в список адресов.
  - Обновляется журнал (дата, версия алгоритма, статус).
  - Обновляется статистика в подвале.

---

### 📌 **4. Автоматический дневной отчет**

#### 📌 Функции:
- Настройка времени запуска (например, 23:00).
- Запуск дневного отчета автоматически.
- Журнал предыдущих запусков.

#### 📌 UI:
- Кнопка **"Автоматический запуск"**.
- Время: `23:00`.
- Статус: ✅ Включен / ❌ Выключен.

#### 📌 Логика:
- При включении:
  - Запускается таймер.
  - Запускается процесс обработки.
  - Обновляется журнал запусков.

---

### 📌 **5. Модель распознавания**

#### 📌 Функции:
- Выбор модели: `Qwen3-VL 4B` (по умолчанию).
- Редактирование промпта.
- Восстановление стандартного промпта.

#### 📌 UI:
- Список моделей: `Qwen3-VL 4B` ▼.
- Кнопка **"Редактировать промпт"**.
- Кнопка **"Восстановить стандартный промпт"**.

#### 📌 Логика:
- При выборе модели:
  - Обновляется модель в настройках.
  - Промпт сохраняется в состоянии приложения.
  - При редактировании: открытие формы редактирования.

---

## 📌 **Интеграция с `header.py`**

- В `header.py` будет использоваться `SETTINGS` из `settings.py`.
- При смене менеджера или темы:
  - Обновляется цвет интерфейса.
  - Обновляется статистика в подвале.
  - Обновляется подборка (если включено).

---

## 📌 **Статистика в подвале**

- Главная строка: **Статистика за месяц**.
- Подробная статистика по нажатию **"Подробнее"**.
- Фильтрация по клиентам (5+ адресов).
- Фильтрация по датам (день, месяц, период).

Все пожелания учтены и структурированы. Теперь можно приступать к реализации технического окна, используя `technical.py` как основной файл.
