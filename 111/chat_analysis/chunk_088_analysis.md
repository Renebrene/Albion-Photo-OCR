### Основные принципы

- **Расписание фотоотчёта** должно быть **независимо** от запуска Qwen и обновления слепков.
- **Автозапуск Qwen** — это отдельный процесс, который можно запускать **в любое время** (включая ночное).
- **Обновление слепков** — это **процесс, связанный с базой данных**, и его можно запускать **вручную** или по расписанию.
- **Журнал выполнения** — это **история всех запусков**, включая **статус** (успешно/ошибка) и **подробности ошибки** (если есть).

## Настройки автоматики

Важно предусмотреть **настройки**, которые позволят пользователю **адаптировать автоматику под свои нужды**:

```text
Автоматически запускать Qwen: [✓]
Автоматически обновлять слепки: [✓]
Автоматически генерировать фотоотчёт: [✓]
```

Также можно добавить:

```text
Максимальное количество одновременных задач: [ 5 ]
```

Это поможет избежать перегрузки сервера при массовом запуске.

## Журнал выполнения

Журнал должен быть **структурированным** и **поисковым**:

```text
┌──────────────────────────────────────────────────────────────┐
│ Журнал выполнения                                           │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│ Дата/время       | Тип задачи       | Статус       | Детали    │
├──────────────────────────────────────────────────────────────┤
│ 16.08.2026 08:00 | Фотоотчёт       | ✅ Успешно   | 100 фото  │
│ 16.08.2026 08:00 | Запуск Qwen     | ✅ Успешно   | 4B       │
│ 16.08.2026 08:00 | Обновление слепков | ✅ Успешно | 100 фото │
│ 15.08.2026 23:59 | Запуск Qwen     | ⚠ Ошибка    | Timeout  │
└──────────────────────────────────────────────────────────────┘
```

Пользователь может **фильтровать** по дате, типу задачи или статусу.
