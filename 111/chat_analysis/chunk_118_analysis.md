### ✅ **Готовая правка для `photos.py`**

Вставь этот код **вместо** текущего `ui.row()` после checkbox:

```python
                                # ----------------------------
                                # Qwen INFO
                                # ----------------------------

                                with ui.row().classes(
                                    "w-full "
                                    "items-start "
                                    "px-2 pt-1"
                                ):

                                    # Клиент · Бренд
                                    ui.label(
                                        f"{photo.db_record.get('client', '')} · "
                                        f"{photo.db_record.get('brand', '')}"
                                    ).classes(
                                        "text-xs text-grey-6"
                                    )

                                    # Описание Qwen (2 строки)
                                    description = photo.db_record.get("description", "")
                                    if description:
                                        ui.label(
                                            f"{description[:40]}..."
                                        ).classes(
                                            "text-xs text-grey-5"
                                        )

                                    # Текст с баннера (если есть)
                                    text = photo.db_record.get("text", "")
                                    if text:
                                        ui.label(
                                            f"Текст: {text[:20]}"
                                        ).classes(
                                            "text-xs text-grey-4"
                                        )
```

---

### 📌 **Что это делает**

1. **Клиент · Бренд**  
   Показывает `client` и `brand` из PostgreSQL, если они есть.

2. **Описание Qwen (2 строки)**  
   Отображает первые 40 символов описания, чтобы не перегружать карточку.

3. **Текст с баннера**  
   Показывает текст с баннера (если он есть), обрезая до 20 символов.

---

### 🚫 **Что не меняем**

- **Не трогаем** `open_photo()` и `photos.py` — всё остается как есть.
- **Не ломаем** PostgreSQL-индексацию и Qwen-обработку.
- **Не меняем** стили и структуру карточки — только добавляем информацию под именем.

---

### 🧠 **Почему это работает**

- `photo.db_record` уже содержит Qwen-метаданные (проверено в `photo_db.py`).
- Мы используем `get()` для полей, чтобы избежать ошибок, если что-то отсутствует.
- Описание обрезается, чтобы не мешать визуальному восприятию.
