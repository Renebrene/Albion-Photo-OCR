```
78/ → 78_001.jpg, 78_002.jpg, ...
79/ → 79_001.jpg, 79_002.jpg, ...
...
95/ → 95_001.jpg, 95_002.jpg, ...
```

### 🔧 Как это сделать

#### 1. **Сначала проверим, что в каждой папке есть файлы с изображениями**

```bash
cd ~/projects/scene_fingerprint_mvp_v02

for d in data/input/{78..95}; do
    printf "%-5s " "$(basename "$d")"
    find "$d" -maxdepth 1 -type f \
      \( -iname "*.jpg" -o -iname "*.jpeg" \
         -o -iname "*.png" -o -iname "*.webp" \) \
      | wc -l
done
```

Если в какой-то папке отсутствуют файлы, это ошибка — мы должны иметь **по 1–100+ изображений в каждой папке**.

---

#### 2. **Переименуем файлы в каждой папке**

```bash
cd ~/projects/scene_fingerprint_mvp_v02

for d in data/input/{78..95}; do
    echo
    echo "=== Processing: $(basename "$d") ==="
    echo "Original files:"
    ls -1 "$d" | grep -Ei '\.jpg$|\.jpeg$|\.png$|\.webp$'

    # Считаем файлы и переименуем
    count=1
    for file in "$d"/*; do
        if [[ -f "$file" && $(file --mime-type -b "$file") =~ "image/.*" ]]; then
            # Извлекаем расширение
            ext="${file##*.}"
            base="${file%.*}"
            new_name="${d%/}_$count.$ext"
            mv "$file" "$new_name"
            count=$((count + 1))
        fi
    done

    echo "Renamed files:"
    ls -1 "$d" | grep -Ei '\.jpg$|\.jpeg$|\.png$|\.webp$'
done
```

### 📌 Что это делает:
- Перебирает папки `78–95`.
- Для каждой папки:
  - Показывает исходные файлы.
  - Переименовывает файлы в формат `папка_индекс.расширение`.
  - Сохраняет порядок (индекс начинается с `001`).
  - Игнорирует неизображения (например, текстовые файлы).
