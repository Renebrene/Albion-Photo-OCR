### 🔍 **Ответ: Размер выходных токенов**

В текущей реализации **Qwen3-VL 4B** (и Qwen2.5-VL 7B) **не задан жёсткий лимит на выходные токены**. По умолчанию модель генерирует ответ до естественного завершения, что может давать **несколько сотен токенов** на одну фотографию. 

---

### 📊 **Как это измеряется в нашем тесте**

В скрипте `benchmark_qwen_vl.py` мы сохраняем:

```text
output_tokens
tokens_sec
seconds
```

Для 20 фотографий можно увидеть, например:

```text
Qwen3-VL 4B
среднее: 180 токенов/фото
```

```text
Qwen2.5-VL 7B
среднее: 240 токенов/фото
```

---

### 📌 **Почему это важно**

Если цель — **ускорить обработку 1000+ фотографий**, можно **ограничить выходные токены** (например, до 256–384), чтобы:

1. **Сократить время генерации** (меньше токенов = быстрее).
2. **Уменьшить нагрузку на модель** (меньше вычислений).
3. **Сэкономить ресурсы** (меньше памяти, меньше времени).

---

### 🚀 **Как это сделать**

В промпте можно добавить ограничение на количество токенов:

```python
"options": {
    "temperature": 0,
    "num_predict": 256  # или 384
}
```

Это уменьшит объём ответа и ускорит обработку. После теста можно сравнить:

- **Скорость** (tok/s)
- **Точность** (не должно быть слишком короткого ответа)
- **Соответствие требованиям** (достаточно ли метаданных?)
