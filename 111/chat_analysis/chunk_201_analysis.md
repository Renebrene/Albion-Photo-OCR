### ✅ **Вывод по проблеме**

Сервер работает, доступ к `/v2/index.html` есть, и `curl` подтверждает это. Ошибка `ERR_CONNECTION_REFUSED` в браузере — **не из-за сервера**, а из-за **маршрутизации или настроек браузера**.

---

### 🔍 **Основные причины и решения**

#### 1. **Неправильный адрес в браузере**
- Если вы открываете `http://localhost:8081` или `http://127.0.0.1:8081`, браузер пытается подключиться **к вашему локальному компьютеру**, а не к серверу `NEURO`.
- **Решение:**  
  Откройте в браузере:  
  ```
  http://192.168.1.5:8081/v2/
  ```  
  или через ZeroTier:  
  ```
  http://10.241.0.111:8081/v2/
  ```

---

#### 2. **Проверка UFW (брандмауэр)**
- У вас есть правило:  
  ```
  8081/tcp on zt+ ALLOW Anywhere
  ```  
  Это разрешает доступ **только через ZeroTier**. Если браузер не в ZeroTier-сети, доступ запрещён.
- **Решение:**  
  Добавьте правило для всех IP-адресов:  
  ```bash
  sudo ufw allow 8081/tcp
  ```
  Проверьте:  
  ```bash
  sudo ufw status | grep 8081
  ```

---

#### 3. **Прокси/VPN в браузере**
- Если вы использовали прокси/VPN, браузер может пытаться подключиться через него, что блокирует доступ к локальному серверу.
- **Решение:**  
  Отключите прокси в браузере:  
  - **Firefox:**  
    `Настройки → Сеть → Настройки прокси → Без прокси`  
  - **Chrome:**  
    `Настройки → Система → Прокси → Автоматически определить прокси`  
  - Добавьте исключение для `localhost` и `127.0.0.1`.

---

#### 4. **Проверка IP-адреса сервера**
- Убедитесь, что сервер слушает все интерфейсы:  
  ```bash
  ss -tulpn | grep 8081
  ```
  Должно быть:  
  ```
  0.0.0.0:8081
  ```
  Если видите `127.0.0.1:8081`, сервер слушает только локально.  
  **Решение:**  
  Убедитесь, что в коде сервера (например, Uvicorn) используется `host="0.0.0.0"`.

---

### 🚀 **Дополнительные проверки**
1. **Проверьте IP-адрес сервера:**  
   ```bash
   hostname -I
   ```
   У вас:  
   ```
   192.168.1.5
   ```

2. **Проверьте, что браузер на том же устройстве:**  
   Если браузер запущен на другом компьютере, используйте `192.168.1.5` или ZeroTier-адрес.

3. **Проверьте, что браузер не использует прокси:**  
   Убедитесь, что в настройках браузера отключены прокси-серверы.

---

### ✅ **Итог**
- Сервер работает и доступен через `curl`.  
- Ошибка в браузере — **не из-за сервера**, а из-за **маршрутизации или настроек браузера**.  
- Откройте `http://192.168.1.5:8081/v2/` или через ZeroTier.  
- Убедитесь, что UFW разрешает доступ к порту 8081 и что прокси не блокирует соединение.

Если всё ещё не открывается — проверьте, не блокирует ли брандмауэр (UFW) порт 8081 для вашей сети.
