Если вы хотите применить изменения и проверить их, выполните следующие шаги:

1. **Перезапустите сервис** (если используется systemd):
   ```bash
   sudo systemctl restart lora
   ```

2. **Посмотрите логи** для подтверждения, что гостевые настройки применяются:
   ```bash
   journalctl -u lora -f
   ```

3. **Проверьте, что ветка `else` вызывает `apply_guest_defaults()`**:
   - Если в логах появится `[USER RESTORE] Guest defaults applied`, значит, всё работает.
   - Если всё ещё отображается `[USER RESTORE] 12 'Гость'`, значит, пользователь "Гость" хранится как обычный пользователь в базе, и нужно будет дополнительно настроить его поведение.
