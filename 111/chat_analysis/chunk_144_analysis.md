## 🧠 **Архитектурные требования**

1. **`data/input`** — входной буфер:
   - Вложенные папки.
   - Рекурсивный сканер.
   - Физические файлы не переносятся.

2. **`data/photos`** — постоянный каталог:
   - Организация по `photo_taken_at`.
   - Физические файлы хранятся в `data/photos/YYYY-MM/DD/PH_00000526.JPG`.
   - `original_filename` сохраняется в БД.

3. **PostgreSQL** — основа истины:
   - `photo_id` — уникальный идентификатор.
   - `source_path` — путь к файлу в `data/input`.
   - `dino_status`, `sort_status`, `preview_status`, `qwen_status` — статусы обработки.
   - `photo_taken_at` — дата съемки (EXIF или дата файла).

## 🚀 **Миграция: шаги**

### 1. **Определить дату съемки**
- Для каждого файла:
  - Пытаться получить `EXIF DateTimeOriginal`.
  - Если отсутствует — использовать дату файла.
  - Если и это ненадежно — использовать дату ingest.

### 2. **Перенос файлов в `data/photos`**
- Для каждой фотографии:
  - Создать папку `data/photos/YYYY-MM/DD/`.
  - Переместить файл в `data/photos/YYYY-MM/DD/PH_00000526.JPG`.
  - Обновить `source_path` в БД на `data/photos/YYYY-MM/DD/PH_00000526.JPG`.

### 3. **Обновление статусов**
- Для существующих записей:
  - Не трогать `dino_status`, `sort_status`, `preview_status`, `qwen_status`.
  - Обновить `source_path` и `path` в БД.

---

## 🔄 **Обработка новых файлов**

### 4. **Инкрементальная обработка**
- При запуске:
  - Сканировать `data/input/` рекурсивно.
  - Сравнивать `source_path` с существующими записями в БД.
  - Только новые файлы регистрируются в БД и получают статусы `pending`.

---

## 🧠 **Обработчики (DINO, сортировка, Qwen)**

### 5. **Работа с БД**
- Обработчики должны:
  - Читать данные из БД.
  - Обновлять статусы (например, `dino_status = done`).
  - Не перепроцессировать уже обработанные файлы.

### 6. **Грид**
- Грид должен:
  - Работать исключительно с БД.
  - Использовать `data/photos` как постоянный каталог.
  - Получать фотографии по `photo_id`.

---

## 📌 **Важные моменты**

- **Физические файлы остаются на месте**.
- **Инкрементальная обработка** — только новые файлы.
