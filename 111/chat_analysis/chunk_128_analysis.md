### 🛠️ **Интегратор для обработки фотографий**

Вот как можно реализовать **интегратор**, который объединит все этапы обработки фотографий в единую систему:

---

## 🧩 **Архитектура интегратора**

```text
+-------------------+     +-------------------+     +-------------------+
|   Photo Ingestor  | -->|     DINO         | -->|     Hybrid        | -->|   Qwen         |
| (Assign photo_id) |     | (Feature Extract) |     | (Scene Matching)  |     | (Description)  |
+-------------------+     +-------------------+     +-------------------+     +-------------------+
          │                        │                        │                        │
          ▼                        ▼                        ▼                        ▼
+-------------------+     +-------------------+     +-------------------+     +-------------------+
|   PostgreSQL DB   | <-- |   DINO Results    | <-- |   Hybrid Results  | <-- |   Qwen Results  |
| (Store metadata)  |     | (photo_id, ...)  |     | (best_id, ...)   |     | (description)   |
+-------------------+     +-------------------+     +-------------------+     +-------------------+
          │                        │                        │                        │
          ▼                        ▼                        ▼                        ▼
+-------------------+     +-------------------+     +-------------------+     +-------------------+
|   Sort Results    | <-- |   Hybrid Output   | <-- |   DINO Output     | <-- |   Qwen Output   |
| (Copy to output)  |     | (best_id, ...)   |     | (features, ...)  |     | (description)   |
+-------------------+     +-------------------+     +-------------------+     +-------------------+
```

---

## 📌 **Функциональные блоки**

### 1. **Photo Ingestor**
- **Задача:** Присвоить `photo_id` и зарегистрировать фотографии в БД.
- **Режимы запуска:**
  - **Кнопка:** Вручную запускать.
  - **Таймер:** Автоматически каждые X минут.
  - **Watcher:** Постоянно мониторить папку на новые файлы.
- **Логика:**
  - Найти новые файлы в `input_dir`.
  - Присвоить уникальный `photo_id` (например, `PH_00000101`).
  - Зарегистрировать в PostgreSQL: `source_path`, `filename`, `photo_id`.
  - Установить статус: `NEW`.

---

### 2. **DINO (Feature Extraction)**
- **Задача:** Извлечь фичи из фотографий.
- **Вход:** `photo_id`, `source_path`.
- **Выход:** `photo_id`, `features` (например, векторы из DINO).
- **Статус:** `RECOGNIZED`.

---

### 3. **Hybrid (Scene Matching)**
- **Задача:** Сопоставить фотографии с известными сценами.
- **Вход:** `features` от DINO.
- **Выход:** `best_id` (например, `85_v33`).
- **Статус:** `SORTED`.

---

### 4. **Qwen (Description)**
- **Задача:** Описать сцену на основе `best_id`.
- **Вход:** `best_id`.
- **Выход:** `description`, `objects_json`, `colors_json`.
- **Статус:** `READY`.

---

### 5. **Sort Results**
- **Задача:** Физически скопировать фотографии в выходную папку.
- **Вход:** `photo_id`, `best_id`, `description`.
- **Выход:** `sorted_path` (например, `data/output/daily/20260818/85_v33/IMG_123.JPG`).
- **Статус:** `SORTED`.

---

### 6. **PostgreSQL DB**
- **Задача:** Хранить метаданные и статусы.
- **Таблица:**
  ```sql
  CREATE TABLE photos (
      photo_id TEXT PRIMARY KEY,
      source_path TEXT,
      filename TEXT,
      address TEXT,
      sorted_path TEXT,
      dino_status TEXT,
      hybrid_status TEXT,
      qwen_status TEXT,
      sort_status TEXT,
      description TEXT,
      objects JSONB,
      colors JSONB
  );
  ```

---

## 🚀 **Режимы запуска**

### 1. **Кнопка (Manual)**
```bash
python run_hybrid_v12.py --input data/input/daily --manual
```
- Запускает Photo Ingestor, DINO, Hybrid, Qwen, Sort Results вручную.

### 2. **Таймер (Scheduled)**
```bash
crontab -e
```
```bash
*/5 * * * * python run_hybrid_v12.py --input data/input/daily --timer
```
- Запускает Photo Ingestor каждые 5 минут.

### 3. **Watcher (Continuous)**
```bash
python run_hybrid_v12.py --input data/input/daily --watcher
```
- Постоянно мониторит папку, регистрирует новые файлы и запускает обработку.

---

## 🧪 **Пример работы**

1. **Фотография появляется в `data/input/daily/`**
2. **Photo Ingestor** присваивает `PH_00000101` и регистрирует в БД.
3. **DINO** извлекает фичи и обновляет статус до `RECOGNIZED`.
4. **Hybrid** находит сцену `85_v33` и обновляет статус до `SORTED`.
5. **Qwen** описывает сцену и обновляет статус до `READY`.
6. **Sort Results** копирует файл в `data/output/daily/20260818/85_v33/IMG_123.JPG`.
7. **Грид** отображает только фотографии с `status = READY`.

## 🧠 **Преимущества**

- **Гибкость:** Поддержка ручного, автоматического и постоянного режимов.
- **Надежность:** Уникальные `photo_id` и проверка на дубликаты.
- **Масштабируемость:** Все этапы можно запускать параллельно.
- **Мониторинг:** Статусы в БД позволяют отслеживать прогресс.
