## 🧠 **Методология теста**
### 1. **Формирование кандидатов**
Для каждого неизвестного клиента:
- Проверить в локальном справочнике (точное совпадение).
- Сгенерировать 3-10 кандидатов (например: `Вольный Дон`, `Волынский Дон`, `Ростов-Дон`, `Дон`).
- Отправить в модель только **кандидаты**, а не весь справочник.

### 2. **Формат запроса**
```json
{
  "input": "Волный Дон",
  "candidates": ["Вольный Дон", "Волынский Дон", "Ростов-Дон", "Дон"],
  "instruction": "Выбери наиболее вероятное соответствие. Если соответствия нет — верни `NONE`."
}
```

### 3. **Ожидаемый формат ответа**
```json
{
  "match": "Вольный Дон",
  "confidence": 0.96,
  "reason": "Точное совпадение с локальным справочником."
}
```

1. **qwen3:8b** лучше справляется с **сложными случаями** (например, `EMBAYGO`), чем `qwen2.5:7b`.
