## 2. ФАЙЛЫ И МОДУЛИ  
- **`app/processing/photo_processor.py`**: Логика обработки фото, включая нормализацию клиентов.  
- **`app/normalization/client_normalizer.py`**: Модуль для нормализации клиентов (например, "Яндеск" → "Яндекс").  
- **`app/web/components/clients.py`**: Загрузка клиентов из `client_directory` вместо статических данных.  
- **`app/web/components/addresses.py`**: Загрузка адресов из `address_directory`.  
- **`app/web/directory_db.py`**: Функции для работы с справочниками (например, `get_clients`, `normalize_client`).  
- **`scripts/benchmark_client_models_25.py`**: Скрипт для сравнения моделей Qwen.  
- **`CREATE TABLE` SQL-скрипты**:  
  - `addresses`, `clients`, `photos` — основные таблицы данных.  
  - `manager_filter_state`, `collections` — хранение состояния фильтров и подборок.  
  - `address_directory`, `client_directory` — справочники клиентов и адресов.
