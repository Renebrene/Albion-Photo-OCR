## 2. ФАЙЛЫ И МОДУЛИ  
- `app/pipeline/queue-batch-add.py` — скрипт массовой загрузки задач в очередь  
- `tools/sweep_v34_groups.py` — анализ группировки изображений по эмбеддингам  
- `app/ocr/` — модуль OCR для распознавания текстовых номеров (не включен в основной пайплайн)  
- `data/fingerprints/84_v34/` — структура подслепков с метаданными, embeddings и centroid  
- `data/output/test_classified/*.json` — результаты распознавания с метриками score/margin  
- `scripts/make_subfingerprints.py` — генерация подслепков на основе кластеризации  
- `recognition.json` — финальный отчёт с распределением файлов по адресам  

---

## 3. АРХИТЕКТУРНЫЕ РЕШЕНИЯ  
- **DINOv2** — основной инструмент для генерации визуальных эмбеддингов  
- **FAISS** — библиотека для быстрого поиска ближайших кандидатов  
- **Модульность** — разделение на pipeline (очереди), ocr (экспериментальный), fingerprint (генерация слепков)  
- **Группировка подслепков** — кластеризация на основе порога сходства (0.89) для разделения сцен  
- **Отказ от OCR в пайплайне** — сохранение OCR как экспериментального модуля из-за низкой точности
