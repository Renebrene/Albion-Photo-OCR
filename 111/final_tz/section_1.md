### ОПИСАНИЕ ПРОЕКТА И ТЕХНИЧЕСКИЙ СТЕК

---

#### 1. ОПИСАНИЕ ПРОЕКТА

**1.1. НАЗНАЧЕНИЕ**  
Проект направлен на автоматизацию сортировки изображений в определённые папки на основе их визуальных характеристик. Основная цель — разработка алгоритма, который с использованием глубокого обучения и кластеризации сможет точно распознавать и группировать изображения.

**1.2. АУДИТОРИЯ**  
- Разработчики: специалисты в области искусственного интеллекта и машинного обучения, работающие над проектом.  
- Рекламное агентство: сотрудники, использующие систему для автоматической сортировки изображений.  
- Клиенты: компании, заказывающие广告服务 с сортировкой изображений для маркетинговых кампаний.  

**1.3. ОСНОВНЫЕ ФУНКЦИИ**  
- Просканирование папок с изображениями.  
- Генерация визуальных фингерпринтов (embeddings) для каждого изображения.  
- Сравнение фингерпринтов для определения схожести изображений.  
- Распределение изображений в соответствующие папки на основе анализа.  
- Возможность корректировки ручного вмешательства для уточнения результатов.  

**1.4. ТЕХНИЧЕСКИЕ ОСОБЕННОСТИ**  
- Использование метода DINOv2 для генерации глобальных и патчевых эмбеддингов.  
- Кластеризация изображений с использованием FAISS для ускорения поиска.  
- Двухступенчатая архитектура: глобальное сравнение для фильтрации, подслепки для уточнения.  
- Использование LLM для разрешения сомнительных кадров.  

---

#### 2. ТЕХНИЧЕСКИЙ СТЕК

**2.1. ОСНОВНЫЕ БИБЛИОТЕКИ**  
- **Deep Image Matching (DINOv2)**: для генерации визуальных фингерпринтов.  
- **FAISS**: для быстрого поиска ближайших кандидатов.  
- **Transformers (LLM)**: для разрешения сомнительных кадров.  
- **NiceGUI**: для визуализации результатов.  

**2.2. СТРУКТУРА ПРОЕКТА**  
```
project/
├── app/
│   ├── core/
│   │   ├── fingerprint.py
│   │   ├── embedder.py
│   │   ├── recognizer.py
│   │   └── scene_analyzer.py
│   └── cli.py
├── data/
│   ├── fingerprints/
│   │   └── *.json, *.npy
│   └── input/
│       └── *.JPG
└── scripts/
    ├── build_subfingerprint_database.py
    ├── benchmark_sub_rerank_v02.py
    └── sort_neighbor_v35_benchmark.py
```

**2.3. ОСНОВНЫЕ МОДУЛИ**  
- **FingerprintManager**: управление фингерпринтами, их сохранением и загрузкой.  
- **Embedder**: генерация глобальных и патчевых эмбеддингов с использованием DINOv2.  
- **Recognizer**: сравнение фингерпринтов и определение соответствующих папок.  
- **SceneAnalyzer**: анализ сцен, кластеризация и уточнение результатов.  

**2.4. НАПИСАННЫЙ КОД**  
- Скрипты для генерации фингерпринтов, их сортировки и анализа.  
- Алгоритмы для сравнения схожести изображений, включая использование подслепков.  
- Использование LLM для разрешения сомнительных кадров.  

**2-5. НЕЗАВЕРШЁННЫЕ ЗАДАЧИ**  
- Добавление системы мониторинга для отслеживания производительности.  
- Проверка и корректировка алгоритма на реальных данных.  
- Документирование изменений и настроек.  
- Улучшение интерфейса для визуализации результатов.
